3.2. 面向对象的设计与实现¶

在介绍线性回归时， 我们逐一讲解了 数据、模型、损失函数 以及优化算法等各个组成部分。 的确， 线性回归是 最简单的机器学习模型之一。 然而，训练它 所用的许多组件，也是本书中其他模型所需要的。 因此， 在深入实现细节之前， 有必要先 设计一些 贯穿全书使用的API。 把深度学习中的组件 当作对象来处理， 我们就可以先 为这些对象定义类 以及它们之间的交互方式。 这种面向对象的 设计思路 将大大简化 我们的讲解，你甚至可能想在自己的项目中采用它。

受PyTorch Lightning等开源库的启发， 从高层来看， 我们希望有三个类： （i）Module包含模型、损失和优化方法； （ii）DataModule提供用于训练和验证的数据加载器； （iii）这两个类通过Trainer类组合起来，使我们能够 在各种硬件平台上训练模型。 本书中的大部分代码都改编自Module和DataModule。我们只在讨论GPU、CPU、并行训练和优化算法时才会涉及Trainer类。

3.2.1. 工具函数¶

为了简化Jupyter 笔记本中的面向对象编程，我们需要几个工具函数。其中一个挑战是，类的定义往往是相当长的代码块。笔记本的可读性要求代码片段简短，并穿插在解释之间，这与Python库中常见的编程风格并不相容。第一个 工具函数让我们可以在创建类之后把函数注册为该类的方法。事实上，我们甚至可以在已经创建了该类的实例之后再这样做！这样就能把一个类的实现拆分到多个代码块中。

def add_to_class(Class):  #@save
    """Register functions as methods in created class."""
    def wrapper(obj):
        setattr(Class, obj.__name__, obj)
    return wrapper

让我们快速看看如何使用它。我们打算实现一个带有方法do的类A。与其把A和do的代码放在同一个代码块中，我们可以先声明类A，并创建一个实例a。

class A:
    def __init__(self):
        self.b = 1

a = A()

接下来，我们像通常那样定义方法do，只是它不在类A的作用域内。取而代之的是，我们用add_to_class来装饰这个方法，并以类A作为其参数。这样一来，该方法就能访问A的成员变量，就如同它原本就包含在A的定义中一样。让我们看看在实例a上调用它时会发生什么。

@add_to_class(A)
def do(self):
    print('Class attribute "b" is', self.b)

a.do()

3.2.2. 模型¶

Module类是我们将要实现的所有模型的基类。至少需要三个方法。第一个是__init__，用于存储可学习的参数；training_step方法接受一个数据批量并返回损失值；最后，configure_optimizers返回用于更新可学习参数的优化方法，或者优化方法的列表。我们还可以选择性地定义validation_step来报告评价指标。 有时，我们会把计算输出的代码放到一个单独的forward方法中，以提高代码的可复用性。

class Module(nn.Module, d2l.HyperParameters):  #@save
    """The base class of models."""
    # No need for save_hyperparam when using Python dataclass
    plot_train_per_epoch: int = field(default=2, init=False)
    plot_valid_per_epoch: int = field(default=1, init=False)
    # Use default_factory to make sure new plots are generated on each run
    board: ProgressBoard = field(default_factory=lambda: ProgressBoard(),
                                 init=False)

    def loss(self, y_hat, y):
        raise NotImplementedError

    # JAX & Flax do not have a forward-method-like syntax. Flax uses setup
    # and built-in __call__ magic methods for forward pass. Adding here
    # for consistency
    def forward(self, X, *args, **kwargs):
        assert hasattr(self, 'net'), 'Neural network is defined'
        return self.net(X, *args, **kwargs)

    def __call__(self, X, *args, **kwargs):
        return self.forward(X, *args, **kwargs)

    def plot(self, key, value, train):
        """Plot a point in animation."""
        assert hasattr(self, 'trainer'), 'Trainer is not inited'
        self.board.xlabel = 'epoch'
        if train:

                self.trainer.num_train_batches
            n = self.trainer.num_train_batches / \
                self.plot_train_per_epoch

            x = self.trainer.epoch + 1
            n = self.trainer.num_val_batches / \
                self.plot_valid_per_epoch
        self.board.draw(x, jax.device_put(value, d2l.cpu()),
                        ('train_' if train else 'val_') + key,
                        every_n=int(n))

        l, grads = jax.value_and_grad(self.loss)(params, batch[:-1],
                                                 batch[-1], state)
        self.plot("loss", l, train=True)
        return l, grads

    def validation_step(self, params, batch, state):
        l = self.loss(params, batch[:-1], batch[-1], state)
        self.plot('loss', l, train=False)

        """To be defined later in :numref:`sec_lazy_init`"""
        raise NotImplementedError

        raise NotImplementedError

3.2.3. 数据¶

        self.save_hyperparameters()
        assert num_gpus == 0, 'No GPU support yet'

        self.train_dataloader = data.train_dataloader()
        self.val_dataloader = data.val_dataloader()
        self.num_train_batches = len(self.train_dataloader)
        self.num_val_batches = (len(self.val_dataloader)
                                if self.val_dataloader is not None else 0)

    def prepare_model(self, model):
        model.trainer = self
        model.board.xlim = [0, self.max_epochs]
        self.model = model

    def fit(self, model, data, key=None):
        self.prepare_data(data)
        self.prepare_model(model)
        self.optim = model.configure_optimizers()

        if key is None:
            root_key = d2l.get_key()
        else:
            root_key = key
        params_key, dropout_key = jax.random.split(root_key)
        key = {'params': params_key, 'dropout': dropout_key}

        dummy_input = next(iter(self.train_dataloader))[:-1]
        variables = model.apply_init(dummy_input, key=key)
        params = variables['params']

        if 'batch_stats' in variables.keys():
            # Here batch_stats will be used later (e.g., for batch norm)
            batch_stats = variables['batch_stats']
        else:
            batch_stats = {}

        # Flax uses optax under the hood for a single state obj TrainState.
        # More will be discussed later in the dropout and batch
        # normalization section
        class TrainState(train_state.TrainState):
            batch_stats: Any
            dropout_rng: jax.random.PRNGKeyArray

        self.state = TrainState.create(apply_fn=model.apply,
                                       params=params,
                                       batch_stats=batch_stats,
                                       dropout_rng=dropout_key,
                                       tx=model.configure_optimizers())
        self.epoch = 0
        self.train_batch_idx = 0
        self.val_batch_idx = 0
        for self.epoch in range(self.max_epochs):
            self.fit_epoch()

    def fit_epoch(self):

3.2.5. 小结¶

为了突出我们未来深度学习实现中的面向对象设计， 上面的类只是展示了它们的对象 如何存储数据以及彼此如何交互。 在本书余下的部分，我们会 通过@add_to_class等方式， 不断丰富这些类的实现。 此外， 这些完整实现的类 保存在D2L库中， 这是一个轻量级工具包，使深度学习的结构化建模变得容易。 特别地，它便于在项目之间复用许多组件，而几乎无需任何改动。例如，我们可以只替换优化器、只替换模型、只替换数据集等等； 这种程度的模块化在全书中以简洁和简单的方式带来回报（这也是我们加入它的原因），它同样能为你自己的项目带来好处。
