3.3. 合成回归数据¶

机器学习的一切都在于从数据中提取信息。 因此你可能会问：从合成数据中究竟能学到什么呢？ 虽然我们可能从本质上并不关心 自己人为编造的数据生成模型里所嵌入的模式， 但这类数据集仍然具有教学价值， 能帮助我们评估学习算法的性质， 并确认我们的实现是否按预期工作。 例如，如果我们创建的数据，其正确参数是先验已知的， 那么就可以检验我们的模型是否真的能恢复它们。

3.3.1. 生成数据集¶

为了简洁起见，本例中我们将在低维空间中进行。 下面的代码片段生成1000个样例， 每个样例的二维特征均从 标准正态分布中抽取。 由此得到的设计矩阵\(\mathbf{X}\) 属于\(\mathbb{R}^{1000 \times 2}\)。 我们通过一个真实值（ground truth）线性函数来生成每个标签， 再用加性噪声\(\boldsymbol{\epsilon}\)对这些标签进行破坏， 噪声对每个样例独立同分布地抽取：

(3.3.1)¶\[\mathbf{y}= \mathbf{X} \mathbf{w} + b + \boldsymbol{\epsilon}.\]

为了方便起见，我们假设\(\boldsymbol{\epsilon}\)抽取自 均值为\(\mu= 0\)、 标准差为\(\sigma = 0.01\)的正态分布。 请注意，为了遵循面向对象的设计， 我们把代码添加到__init__方法中，该方法由d2l.DataModule的子类定义（该类在 3.2.3节 中介绍）。 允许设置任何额外的超参数是一种好做法。 我们通过save_hyperparameters()来实现这一点。 batch_size将在稍后确定。

pytorchmxnetjaxtensorflow
class SyntheticRegressionData(d2l.DataModule):  #@save
    """Synthetic data for linear regression."""
    def __init__(self, w, b, noise=0.01, num_train=1000, num_val=1000,
                 batch_size=32):
        super().__init__()
        self.save_hyperparameters()
        n = num_train + num_val
        self.X = torch.randn(n, len(w))
        noise = torch.randn(n, 1) * noise
        self.y = torch.matmul(self.X, w.reshape((-1, 1))) + b + noise

class SyntheticRegressionData(d2l.DataModule):  #@save
    """Synthetic data for linear regression."""
    def __init__(self, w, b, noise=0.01, num_train=1000, num_val=1000,
                 batch_size=32):
        super().__init__()
        self.save_hyperparameters()
        n = num_train + num_val
        self.X = np.random.randn(n, len(w))
        noise = np.random.randn(n, 1) * noise
        self.y = np.dot(self.X, w.reshape((-1, 1))) + b + noise

class SyntheticRegressionData(d2l.DataModule):  #@save
    """Synthetic data for linear regression."""
    def __init__(self, w, b, noise=0.01, num_train=1000, num_val=1000,
                 batch_size=32):
        super().__init__()
        self.save_hyperparameters()
        n = num_train + num_val
        key = jax.random.PRNGKey(0)
        key1, key2 = jax.random.split(key)
        self.X = jax.random.normal(key1, (n, w.shape[0]))

3.3.2. 读取数据集¶

训练机器学习模型通常需要对数据集进行多遍遍历， 每次抓取一个小批量的样例。 然后用这些数据来更新模型。 为了说明其工作原理，我们 实现get_dataloader方法， 并把它注册到SyntheticRegressionData类中，注册方式为add_to_class（该函数在 3.2.1节 中介绍）。 该方法接受批量大小、特征矩阵 和标签向量，并生成大小为batch_size的小批量。 因此，每个小批量都由一个特征与标签的元组组成。 请注意，我们需要留意当前处于训练模式还是验证模式： 在前一种模式下，我们希望以随机顺序读取数据； 而在后一种模式下，能够按预先定义的顺序读取数据 可能对调试很重要。

pytorchmxnetjaxtensorflow
@d2l.add_to_class(SyntheticRegressionData)
def get_dataloader(self, train):
    if train:
        indices = list(range(0, self.num_train))
        # The examples are read in random order
        random.shuffle(indices)
    else:
        indices = list(range(self.num_train, self.num_train+self.num_val))
    for i in range(0, len(indices), self.batch_size):
        batch_indices = torch.tensor(indices[i: i+self.batch_size])
        yield self.X[batch_indices], self.y[batch_indices]

为了建立一些直观认识，让我们检查第一个小批量的 数据。每个小批量的特征既提供了它的批量大小，也提供了输入特征的维数。 同样，我们的小批量标签也会具有由batch_size给出的匹配形状。

X, y = next(iter(data.train_dataloader()))
print('X shape:', X.shape, '\ny shape:', y.shape)

这一调用看似平淡无奇， 但iter(data.train_dataloader()) 却展示了Python面向对象设计的强大之处。 请注意，我们为SyntheticRegressionData类添加了一个方法， 而这是在创建data对象之后才完成的。 尽管如此，该对象仍然受益于 事后（ex post facto）向该类添加的功能。

在整个迭代过程中，我们会获得不同的小批量， 直到整个数据集都被遍历完（不妨一试）。 虽然上面实现的迭代方式在教学上很好， 但它的低效在某些情况下会给处理实际问题带来麻烦。 例如，它要求我们把所有数据都加载到内存中， 并且要执行大量的随机内存访问。 深度学习框架中实现的内置迭代器 要高效得多，而且它们可以处理 存储在文件中的数据、 通过流接收的数据， 以及即时生成或处理的数据等来源。 接下来，让我们尝试用内置迭代器来实现同样的方法。

3.3.3. 数据加载器的简洁实现¶

与其自己编写迭代器， 我们可以调用框架中已有的API来加载数据。 和之前一样，我们需要一个特征为X、标签为y的数据集。 除此之外，我们在内置数据加载器中设置batch_size， 让它高效地处理样例的打乱工作。

def get_tensorloader(self, tensors, train, indices=slice(0, None)):
    tensors = tuple(a[indices] for a in tensors)

3.3.4. 小结¶

数据加载器提供了一种便捷的方式，把 加载和操作数据的过程抽象出来。 这样一来，同一个机器学习算法 无需修改就能处理许多不同类型和数据源的数据。 数据加载器的一个优点 在于它们可以组合。 例如，我们可能先加载图像， 然后用一个后处理滤波器 对图像进行裁剪或以其他方式修改。 因此，数据加载器可以用来 描述一整个数据处理流水线。

至于模型本身，二维线性模型 大概是我们能遇到的最简单的模型了。 它让我们能够检验回归模型的准确率， 而不必担心数据量不足 或方程组欠定。 我们将在下一节中充分利用这一点。
