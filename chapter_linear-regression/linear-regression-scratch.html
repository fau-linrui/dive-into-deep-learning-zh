3.4. 线性回归的从零开始实现¶

我们现在已经准备好， 来实现一个功能完整的线性回归。 在本节中， 我们将从零开始实现整个方法， 包括：(i) 模型；(ii) 损失函数； (iii) 小批量随机梯度下降优化器； (iv) 把所有这些部分串联起来的训练函数。 最后，我们将运行 3.3节 中的合成数据生成器， 并把我们的模型应用到 生成的数据集上。 虽然现代深度学习框架 几乎可以自动完成所有这些工作， 但从零开始实现是 确保你真正理解自己在做什么的唯一途径。 此外，当需要定制模型、 定义自己的层或损失函数时， 理解底层的工作原理将会很有帮助。 在本节中，我们将只依赖 张量和自动微分。 稍后，我们将介绍一种更简洁的实现， 它利用深度学习框架的各种花哨功能， 同时保留下面这种实现的结构。

3.4.1. 定义模型¶

在能够通过小批量SGD开始优化模型参数之前， 我们需要先有一些参数。 下面，我们通过从均值为0、 标准差为0.01的正态分布中抽取随机数 来初始化权重。 这个魔法数字0.01在实践中往往效果很好， 但你可以通过参数sigma 指定一个不同的值。 此外，我们把偏置设为0。 请注意，为了遵循面向对象的设计， 我们把代码添加到d2l.Module子类的__init__方法中（该类在 3.2.2节 中介绍）。

pytorchmxnetjaxtensorflow
class LinearRegressionScratch(d2l.Module):  #@save
    """The linear regression model implemented from scratch."""
    def __init__(self, num_inputs, lr, sigma=0.01):
        super().__init__()
        self.save_hyperparameters()
        self.w = torch.normal(0, sigma, (num_inputs, 1), requires_grad=True)
        self.b = torch.zeros(1, requires_grad=True)

class LinearRegressionScratch(d2l.Module):  #@save
    """The linear regression model implemented from scratch."""
    def __init__(self, num_inputs, lr, sigma=0.01):
        super().__init__()
        self.save_hyperparameters()
        self.w = np.random.normal(0, sigma, (num_inputs, 1))
        self.b = np.zeros(1)
        self.w.attach_grad()
        self.b.attach_grad()

class LinearRegressionScratch(d2l.Module):  #@save
    """The linear regression model implemented from scratch."""
    num_inputs: int
    lr: float
    sigma: float = 0.01

    def setup(self):
        self.w = self.param('w', nn.initializers.normal(self.sigma),
                            (self.num_inputs, 1))
        self.b = self.param('b', nn.initializers.zeros, (1))

class LinearRegressionScratch(d2l.Module):  #@save
    """The linear regression model implemented from scratch."""
    def __init__(self, num_inputs, lr, sigma=0.01):
        super().__init__()
        self.save_hyperparameters()
        w = tf.random.normal((num_inputs, 1), mean=0, stddev=0.01)
        b = tf.zeros(1)
        self.w = tf.Variable(w, trainable=True)
        self.b = tf.Variable(b, trainable=True)

3.4.2. 定义损失函数¶

由于更新模型需要计算损失函数的梯度， 我们应当先定义损失函数。 这里我们使用 (3.1.5) 中的平方损失函数。 在实现中，我们需要把真实值y 变换成预测值的形状y_hat。 下面的方法返回的结果 也将具有与y_hat相同的形状。 我们还返回小批量中 所有样例的平均损失值。

3.4.3. 定义优化算法¶

正如 3.1节 中所讨论的， 线性回归有闭式解。 然而，我们这里的目标是说明 如何训练更一般的神经网络， 而这要求我们教你 如何使用小批量SGD。 因此，我们将借此机会 介绍你的第一个可运行的SGD示例。 在每一步中，使用从数据集中 随机抽取的一个小批量， 我们估计损失 关于参数的梯度。 接下来，我们沿着 可能降低损失的方向更新参数。

下面的代码在给定一组参数和学习率lr的情况下 执行更新。 由于我们的损失是在小批量上求平均计算得到的， 因此不需要根据批量大小调整学习率。 在后面的章节中，我们将研究 当分布式大规模学习中出现非常大的小批量时， 应该如何调整学习率。 目前，我们可以忽略这种依赖关系。

pytorchmxnetjaxtensorflow

我们定义自己的SGD类， 它是d2l.HyperParameters的子类（该类在 3.2.1节 中介绍）， 使其API与内置的SGD优化器相似。 我们在step方法中更新参数。 zero_grad方法把所有梯度设为0， 它必须在反向传播步骤之前运行。

class SGD(d2l.HyperParameters):  #@save
    """Minibatch stochastic gradient descent."""
    def __init__(self, params, lr):
        self.save_hyperparameters()

    def step(self):
        for param in self.params:
            param -= self.lr * param.grad

    def zero_grad(self):
        for param in self.params:
            if param.grad is not None:
                param.grad.zero_()

我们定义自己的SGD类， 它是d2l.HyperParameters的子类（该类在 3.2.1节 中介绍）， 使其API与内置的SGD优化器相似。 我们在step方法中更新参数。 该方法接受一个可以忽略的batch_size参数。

class SGD(d2l.HyperParameters):  #@save

class SGD(d2l.HyperParameters):  #@save
    """Minibatch stochastic gradient descent."""
    # The key transformation of Optax is the GradientTransformation
    # defined by two methods, the init and the update.
    # The init initializes the state and the update transforms the gradients.
    # https://github.com/deepmind/optax/blob/master/optax/_src/transform.py
    def __init__(self, lr):
        self.save_hyperparameters()

    def init(self, params):
        # Delete unused params
        del params
        return optax.EmptyState

    def update(self, updates, state, params=None):
        del params
        # When state.apply_gradients method is called to update flax's
        # train_state object, it internally calls optax.apply_updates method
        # adding the params to the update equation defined below.
        updates = jax.tree_util.tree_map(lambda g: -self.lr * g, updates)
        return updates, state

    def __call__():
        return optax.GradientTransformation(self.init, self.update)

我们定义自己的SGD类， 它是d2l.HyperParameters的子类（该类在 3.2.1节 中介绍）， 使其API与内置的SGD优化器相似。 我们在apply_gradients方法中更新参数。 它接受一个参数与梯度对的列表。

class SGD(d2l.HyperParameters):  #@save
    """Minibatch stochastic gradient descent."""
    def __init__(self, lr):
        self.save_hyperparameters()

    def apply_gradients(self, grads_and_vars):
        for grad, param in grads_and_vars:
            param.assign_sub(self.lr * grad)

3.4.4. 训练¶

现在我们已经把所有部分都准备好了 （参数、损失函数、模型和优化器）， 可以实现主要的训练循环了。 完全理解这段代码至关重要， 因为对于本书中介绍的 每一个其他深度学习模型， 你都会使用类似的训练循环。 在每个轮（epoch）中，我们遍历 整个训练数据集， 对每个样例各过一遍 （假设样例数 能被批量大小整除）。 在每个迭代（iteration）中，我们抓取一个小批量的训练样例， 并通过模型的training_step方法计算其损失。 然后我们计算损失关于每个参数的梯度。 最后，我们调用优化算法 来更新模型参数。 总之，我们将执行下面的循环：

  • 初始化参数\((\mathbf{w}, b)\)

  • 重复直到完成

    • 计算梯度\(\mathbf{g} \leftarrow \partial_{(\mathbf{w},b)} \frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} l(\mathbf{x}^{(i)}, y^{(i)}, \mathbf{w}, b)\)

    • 更新参数\((\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \eta \mathbf{g}\)

回想一下，我们在 3.3节 中生成的 合成回归数据集并不提供验证数据集。 然而在大多数情况下， 我们会希望有一个验证数据集 来衡量模型的质量。 这里我们在每一轮中 把验证数据加载器过一遍，以衡量模型性能。 按照我们的面向对象设计， prepare_batch和fit_epoch方法 注册在d2l.Trainer类中 （该类在 3.2.4节 中介绍）。

@d2l.add_to_class(d2l.Trainer)  #@save
def fit_epoch(self):
    self.model.train()
    for batch in self.train_dataloader:
        loss = self.model.training_step(self.prepare_batch(batch))
        self.optim.zero_grad()

            self.model.validation_step(self.prepare_batch(batch))
        self.val_batch_idx += 1

def fit_epoch(self):
    self.model.training = True
    if self.state.batch_stats:
        # Mutable states will be used later (e.g., for batch norm)
        for batch in self.train_dataloader:
            (_, mutated_vars), grads = self.model.training_step(self.state.params,
                                                           self.prepare_batch(batch),
                                                           self.state)
            self.state = self.state.apply_gradients(grads=grads)
            # Can be ignored for models without Dropout Layers
            self.state = self.state.replace(
                dropout_rng=jax.random.split(self.state.dropout_rng)[0])
            self.state = self.state.replace(batch_stats=mutated_vars['batch_stats'])
            self.train_batch_idx += 1
    else:
        for batch in self.train_dataloader:
            _, grads = self.model.training_step(self.state.params,
                                                self.prepare_batch(batch),
                                                self.state)
            self.state = self.state.apply_gradients(grads=grads)
            # Can be ignored for models without Dropout Layers
            self.state = self.state.replace(
                dropout_rng=jax.random.split(self.state.dropout_rng)[0])
            self.train_batch_idx += 1

    if self.val_dataloader is None:
        return
    self.model.training = False
    for batch in self.val_dataloader:
        self.model.validation_step(self.state.params,
                                   self.prepare_batch(batch),
                                   self.state)
        self.val_batch_idx += 1

@d2l.add_to_class(d2l.Trainer)  #@save
def prepare_batch(self, batch):
    return batch

@d2l.add_to_class(d2l.Trainer)  #@save
def fit_epoch(self):
    self.model.training = True
    for batch in self.train_dataloader:
        with tf.GradientTape() as tape:
            loss = self.model.training_step(self.prepare_batch(batch))
        grads = tape.gradient(loss, self.model.trainable_variables)
        if self.gradient_clip_val > 0:
            grads = self.clip_gradients(self.gradient_clip_val, grads)
        self.optim.apply_gradients(zip(grads, self.model.trainable_variables))
        self.train_batch_idx += 1
    if self.val_dataloader is None:
        return
    self.model.training = False
    for batch in self.val_dataloader:
        self.model.validation_step(self.prepare_batch(batch))
        self.val_batch_idx += 1

我们不应把精确恢复 真实参数的能力视为理所当然。 一般来说，对于深度模型， 参数的唯一解并不存在， 而且即便是线性模型， 也只有在没有任何特征 与其他特征线性相关时， 才可能精确恢复参数。 然而，在机器学习中， 我们往往并不那么关心 恢复真实的潜在参数， 而更关心那些 能带来高度准确预测的参数 (Vapnik, 1992)。 幸运的是，即使在困难的优化问题上， 随机梯度下降也常常能找到非常好的解， 部分原因在于，对于深度网络， 存在许多参数配置 能够带来高度准确的预测。

3.4.5. 小结¶

在本节中，我们朝着设计深度学习系统 迈出了重要的一步， 实现了一个功能完整的 神经网络模型和训练循环。 在此过程中，我们构建了数据加载器、 模型、损失函数、优化过程， 以及一个可视化与监控工具。 我们是通过组合一个包含训练模型 所需的全部相关组件的Python对象来做到这一点的。 虽然这还不是专业级的实现， 但它完全可用，而且这样的代码 已经能帮助你快速解决一些小问题。 在接下来的几节中，我们将看到如何做到这一点： 既更简洁（避免样板代码）， 又更高效（充分发挥GPU的潜力）。
