6.3. 参数初始化¶

既然我们已经知道如何访问参数， 接下来看看如何正确地初始化它们。 我们在 5.4节 中讨论过正确初始化的必要性。 深度学习框架为其各层提供了默认的随机初始化。 然而，我们常常希望按照各种其他方案来初始化权重。 框架提供了最常用的方案， 也允许创建自定义的初始化器。

pytorchmxnetjaxtensorflow
import torch
from torch import nn

默认情况下，PyTorch 通过从根据输入和输出维度计算出的范围中均匀抽取， 来初始化权重矩阵和偏置矩阵。 PyTorch 的 nn.init 模块提供了多种 预置的初始化方法。

net = nn.Sequential(nn.LazyLinear(8), nn.ReLU(), nn.LazyLinear(1))
X = torch.rand(size=(2, 4))
net(X).shape

from mxnet import init, np, npx
from mxnet.gluon import nn

npx.set_np()

默认情况下，MXNet 通过从均匀分布 \(U(-0.07, 0.07)\) 中随机抽取来初始化权重参数， 并把偏置参数置零。 MXNet 的 init 模块提供了多种 预置的初始化方法。

net = nn.Sequential()
net.add(nn.Dense(8, activation='relu'))
net.add(nn.Dense(1))
net.initialize()  # Use the default initialization method

X = np.random.uniform(size=(2, 4))
net(X).shape

import jax
from flax import linen as nn
from jax import numpy as jnp
from d2l import jax as d2l

默认情况下，Flax 使用 jax.nn.initializers.lecun_normal 初始化权重， 即从以0为中心、标准差设为 \(1 / \textrm{fan}_{\textrm{in}}\) 的平方根的截断正态分布中抽取样本， 其中 fan_in 是权重张量中输入单元的数量。偏置 参数全部置零。 JAX 的 nn.initializers 模块提供了多种 预置的初始化方法。

net = nn.Sequential([nn.Dense(8), nn.relu, nn.Dense(1)])
X = jax.random.uniform(d2l.get_key(), (2, 4))
params = net.init(d2l.get_key(), X)
net.apply(params, X).shape

import tensorflow as tf

默认情况下，Keras 通过从根据输入和输出维度计算出的范围中均匀抽取来初始化权重矩阵，偏置参数则全部置零。 TensorFlow 在根模块和 keras.initializers 模块中都提供了多种初始化方法。

net = tf.keras.models.Sequential([
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(4, activation=tf.nn.relu),
    tf.keras.layers.Dense(1),
])

X = tf.random.uniform((2, 4))
net(X).shape

6.3.1. 内置初始化¶

让我们从调用内置初始化器开始。 下面的代码把所有可调权重参数 初始化为标准差为0.01的高斯随机变量， 同时把偏置参数清零。

pytorchmxnetjaxtensorflow
def init_normal(module):
    if type(module) == nn.Linear:

6.3.1.1. 自定义初始化¶

有时，我们需要的初始化方法 并未由深度学习框架提供。 在下面的例子中，我们为任意权重参数 \(w\) 定义一个使用如下奇怪分布的初始化器：

(6.3.1)¶\[\begin{split}\begin{aligned} w \sim \begin{cases} U(5, 10) & \textrm{ with probability } \frac{1}{4} \\ 0 & \textrm{ with probability } \frac{1}{2} \\ U(-10, -5) & \textrm{ with probability } \frac{1}{4} \end{cases} \end{aligned}\end{split}\]
pytorchmxnetjaxtensorflow

同样，我们实现一个 my_init 函数并应用到 net 上。

def my_init(module):
    if type(module) == nn.Linear:
        print("Init", *[(name, param.shape)
                        for name, param in module.named_parameters()][0])
        nn.init.uniform_(module.weight, -10, 10)
        module.weight.data *= module.weight.data.abs() >= 5

net.apply(my_init)
net[0].weight[:2]

请注意，我们总是可以选择 直接设置参数。

net[0].weight.data[:] += 1
net[0].weight.data[0, 0] = 42
net[0].weight.data[0]

这里我们定义 Initializer 类的一个子类。 通常，我们只需要实现 _init_weight 函数， 它接受一个张量参数（data）， 并把期望的初始值赋给它。

class MyInit(init.Initializer):
    def _init_weight(self, name, data):
        print('Init', name, data.shape)
        data[:] = np.random.uniform(-10, 10, data.shape)
        data *= np.abs(data) >= 5

net.initialize(MyInit(), force_reinit=True)
net[0].weight.data()[:2]

请注意，我们总是可以选择 直接设置参数。

net[0].weight.data()[:] += 1
net[0].weight.data()[0, 0] = 42
net[0].weight.data()[0]

JAX 初始化函数接受 PRNGKey、shape 和 dtype 作为参数。这里我们实现函数 my_init， 它在给定形状和数据类型时返回期望的张量。

def my_init(key, shape, dtype=jnp.float_):
    data = jax.random.uniform(key, shape, minval=-10, maxval=10)
    return data * (jnp.abs(data) >= 5)

net = nn.Sequential([nn.Dense(8, kernel_init=my_init), nn.relu, nn.Dense(1)])
params = net.init(d2l.get_key(), X)
print(params['params']['layers_0']['kernel'][:, :2])

在 JAX 和 Flax 中初始化参数时，返回的参数字典 具有 flax.core.frozen_dict.FrozenDict 类型。在 JAX 生态系统中 不建议直接修改数组的值， 因此这些数据类型通常是不可变的。可以使用 params.unfreeze() 来进行修改。

这里我们定义 Initializer 的一个子类，并实现 __call__ 函数，它在给定形状和数据类型时返回期望的张量。

class MyInit(tf.keras.initializers.Initializer):
    def __call__(self, shape, dtype=None):
        data=tf.random.uniform(shape, -10, 10, dtype=dtype)
        factor=(tf.abs(data) >= 5)
        factor=tf.cast(factor, tf.float32)
        return data * factor

net = tf.keras.models.Sequential([
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(
        4,
        activation=tf.nn.relu,
        kernel_initializer=MyInit()),
    tf.keras.layers.Dense(1),
])

net(X)
print(net.layers[1].weights[0])

请注意，我们总是可以选择 直接设置参数。

net.layers[1].weights[0][:].assign(net.layers[1].weights[0] + 1)
net.layers[1].weights[0][0, 0].assign(42)
net.layers[1].weights[0]
