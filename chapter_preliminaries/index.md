# 预备知识
:label:`chap_preliminaries`

为了开始深度学习之旅，
你需要掌握一些生存技能：
（i）存储和操作数据的技术；
（ii）从各种来源读取数据并进行预处理的库；
（iii）我们用于处理高维数据元素的基本线性代数运算知识；
（iv）足以判断应该朝哪个方向调整每个参数以减小损失函数的微积分知识；
（v）自动计算导数的能力，这样你就可以把刚学的大部分微积分知识抛在脑后；
（vi）对概率的基本掌握——概率是我们在不确定性下进行推理的主要语言；
以及（vii）在遇到困难时从官方文档中寻找答案的能力。

简而言之，本章快速介绍你理解本书*大部分*技术内容所需的基础知识。
