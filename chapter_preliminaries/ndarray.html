2.1. 数据操作¶

为了完成任何事情，我们都需要某种方式来存储和操作数据。 一般来说，处理数据时有两件重要的事要做： (i) 获取数据； (ii) 数据进入计算机后对其进行处理。 如果没有任何方式存储数据，那么获取数据就毫无意义， 因此作为起点，让我们从\(n\)维数组入手， 我们也把它称为张量（tensor）。 如果你已经了解NumPy科学计算包， 那么这部分内容对你来说将轻而易举。 对于所有现代深度学习框架， 张量类（MXNet中的ndarray， PyTorch和TensorFlow中的Tensor） 都与NumPy的ndarray类似， 但额外增加了几项杀手级特性。 首先，张量类支持自动微分。 其次，它利用GPU加速数值计算， 而NumPy只能在CPU上运行。 这些特性使得神经网络 既易于编写代码，又运行得很快。

2.1.1. 入门¶

pytorchmxnetjaxtensorflow

首先，我们导入PyTorch库。 请注意，该包的名称是torch。

import torch

首先，我们从MXNet导入np（numpy）和 npx（numpy_extension）模块。 其中，np模块包含 NumPy支持的函数， 而npx模块包含一组扩展函数， 用于在类NumPy环境中 支持深度学习。 使用张量时，我们几乎总是会 调用set_np函数： 这是为了与其他MXNet组件的 张量处理保持兼容。

from mxnet import np, npx

npx.set_np()

import jax
from jax import numpy as jnp

首先，我们导入tensorflow。 为简洁起见，实践者 通常将别名指定为tf。

import tensorflow as tf

张量表示一个由数值组成的（可能是多维的）数组。 在一维情形下，即数据只需要一个轴时， 这样的张量称为向量（vector）。 有两个轴时，张量称为矩阵（matrix）。 有\(k > 2\)个轴时，我们不再使用这些专门名称， 而直接称该对象为\(k^\textrm{th}\)-阶张量。

pytorchmxnetjaxtensorflow

PyTorch提供了多种函数， 用于创建预先填充了数值的新张量。 例如，通过调用arange(n)， 我们可以创建一个由均匀间隔数值组成的向量， 从0开始（包含0）， 到n结束（但不包含在内）。 默认情况下，间隔大小为\(1\)。 除非另有说明， 新张量存储在内存中， 并指定用于基于CPU的计算。

x = torch.arange(12, dtype=torch.float32)
x

这些数值中的每一个都称为 张量的一个元素（element）。 张量x包含12个元素。 我们可以通过张量的numel方法 查看其中元素的总数。

x.numel()

2.1.3. 运算¶

现在，我们已经知道如何构造张量， 以及如何读写张量的元素， 接下来就可以开始用各种数学运算 来操作它们。 在这些运算中，最有用的一类 是按元素（elementwise）运算。 这类运算把标准的标量运算 作用于张量的每一个元素。 对于以两个张量为输入的函数， 按元素运算会对每一对对应的元素 应用某种标准的二元运算符。 我们可以从任何由标量映射到标量的函数出发， 构造一个按元素函数。

在数学记号中，我们用签名 \(f: \mathbb{R} \rightarrow \mathbb{R}\) 来表示这类一元标量运算符（只接受一个输入）。 这只说明该函数把任意实数 映射为另一个实数。 大多数标准运算符，包括像\(e^x\)这样的一元运算符，都可以按元素应用。

pytorchmxnetjaxtensorflow
torch.exp(x)

np.exp(x)

jnp.exp(x)

tf.exp(x)

同样，我们用签名 \(f: \mathbb{R}, \mathbb{R} \rightarrow \mathbb{R}\) 来表示二元标量运算符， 它把一对实数 映射为一个（单个）实数。 给定任意两个形状相同的向量\(\mathbf{u}\) 和\(\mathbf{v}\)， 再给定一个二元运算符\(f\)，我们就能得到向量 \(\mathbf{c} = F(\mathbf{u},\mathbf{v})\)， 只需令\(c_i \gets f(u_i, v_i)\)对所有\(i\)成立， 其中\(c_i, u_i\)和\(v_i\)分别是 向量\(\mathbf{c}, \mathbf{u}\)和\(\mathbf{v}\)的第\(i^\textrm{th}\)个元素。 这里，我们通过把标量函数提升为 按元素的向量运算， 得到了向量值函数 \(F: \mathbb{R}^d, \mathbb{R}^d \rightarrow \mathbb{R}^d\)。 常见的标准算术运算符—— 加法（+）、减法（-）、 乘法（*）、除法（/） 和求幂（**）—— 都已被提升为适用于任意形状、 形状相同张量的按元素运算。

pytorchmxnetjaxtensorflow

y = np.array([2, 2, 2, 2])
x + y, x - y, x * y, x / y, x ** y

x = jnp.array([1.0, 2, 4, 8])
y = jnp.array([2, 2, 2, 2])
x + y, x - y, x * y, x / y, x ** y

x = tf.constant([1.0, 2, 4, 8])
y = tf.constant([2.0, 2, 2, 2])
x + y, x - y, x * y, x / y, x ** y

除按元素计算之外， 我们还可以执行线性代数运算， 例如点积和矩阵乘法。 我们将在 2.3节 中 详细讨论这些内容。

我们还可以连结多个张量， 把它们首尾相接地堆叠起来，形成一个更大的张量。 我们只需提供一个张量列表， 并告诉系统沿哪个轴连结。 下面的例子展示了沿行（轴0） 而不是沿列（轴1）连结两个矩阵时会发生什么。 我们可以看到，第一个输出的轴0长度（\(6\)） 是两个输入张量轴0长度之和（\(3 + 3\)）； 而第二个输出的轴1长度（\(8\)） 是两个输入张量轴1长度之和（\(4 + 4\)）。

2.1.4. 广播¶

到现在为止，你已经知道如何 对两个形状相同的张量 执行按元素的二元运算。 在某些条件下， 即使形状不同， 我们仍然可以通过调用广播机制（broadcasting） 来执行按元素的二元运算。 广播按照以下两步流程进行： (i) 沿长度为1的轴复制元素， 扩展一个或两个数组， 使得这一变换之后 两个张量具有相同的形状； (ii) 对得到的数组 执行按元素运算。

pytorchmxnetjaxtensorflow
a = torch.arange(3).reshape((3, 1))
b = torch.arange(2).reshape((1, 2))
a, b

a = np.arange(3).reshape(3, 1)
b = np.arange(2).reshape(1, 2)
a, b

a = jnp.arange(3).reshape((3, 1))
b = jnp.arange(2).reshape((1, 2))
a, b

a = tf.reshape(tf.range(3), (3, 1))
b = tf.reshape(tf.range(2), (1, 2))
a, b

由于a和b分别是\(3\times1\) 和\(1\times2\)的矩阵， 它们的形状并不匹配。 广播会先沿列复制矩阵a、 沿行复制矩阵b， 然后按元素相加，从而产生一个更大的\(3\times2\)矩阵。

a + b

2.1.5. 节省内存¶

运行运算可能会导致为存放结果而 分配新的内存。 例如，如果我们写Y = X + Y， 就会解除Y原先指向的张量， 转而让Y指向新分配的内存。 我们可以用Python的id()函数演示这一问题， 该函数给出所引用对象在内存中的确切地址。 请注意，在运行Y = Y + X之后， id(Y)指向了不同的位置。 这是因为Python先计算Y + X， 为结果分配新的内存， 然后再让Y指向内存中的这个新位置。

before = id(Y)
Y = Y + X
id(Y) == before

这种做法不可取，原因有二。 首先，我们不希望总是到处 不必要地分配内存。 在机器学习中，我们往往有 数百兆字节的参数， 并且每秒要多次更新它们。 只要可能，我们就希望原地执行这些更新。 其次，我们可能从多个变量 指向同一组参数。 如果不是原地更新， 我们就必须小心地更新所有这些引用， 以免引起内存泄漏， 或者无意中引用了过期的参数。

pytorchmxnetjaxtensorflow

幸运的是，执行原地运算很容易。 我们可以把运算结果赋给 之前已经分配好的数组Y， 也就是使用切片记号：Y[:] = <expression>。 为了说明这一概念， 我们先覆盖张量Z的值， 即用zeros_like把它初始化为 与Y具有相同的形状。

Z = torch.zeros_like(Y)
print('id(Z):', id(Z))
Z[:] = X + Y
print('id(Z):', id(Z))

如果X的值在后续计算中不再使用， 我们还可以用X[:] = X + Y或X += Y 来减少该运算的内存开销。

before = id(X)
X += Y
id(X) == before

幸运的是，执行原地运算很容易。 我们可以把运算结果赋给 之前已经分配好的数组Y， 也就是使用切片记号：Y[:] = <expression>。 为了说明这一概念， 我们先覆盖张量Z的值， 即用zeros_like把它初始化为 与Y具有相同的形状。

# JAX arrays do not allow in-place operations

Variables是TensorFlow中可变的状态容器。它们提供 了一种存储模型参数的方式。 我们可以用assign把运算结果赋给一个Variable。 为了说明这一概念， 我们先覆盖Variable Z的值， 即用zeros_like把它初始化为 与Y具有相同的形状。

Z = tf.Variable(tf.zeros_like(Y))
print('id(Z):', id(Z))
Z.assign(X + Y)
print('id(Z):', id(Z))

即使你已经把状态持久地存储在Variable中， 你可能还希望进一步减少内存占用， 办法是避免为非模型参数的张量分配多余的内存。 由于TensorFlow的Tensors是不可变的， 而且梯度不会通过Variable赋值流动， 因此TensorFlow没有提供显式地 原地执行单个运算的方式。

不过，TensorFlow提供了tf.function装饰器， 可以把计算包装进一张TensorFlow图， 在运行前对这张图进行编译和优化。 这使得TensorFlow能够剪除未使用的值， 并复用不再需要的先前分配。 这就把TensorFlow计算的内存开销降至最低。

@tf.function
def computation(X, Y):
    Z = tf.zeros_like(Y)  # This unused value will be pruned out
    A = X + Y  # Allocations will be reused when no longer needed
    B = A + Y
    C = B + Y
    return C + Y

computation(X, Y)
