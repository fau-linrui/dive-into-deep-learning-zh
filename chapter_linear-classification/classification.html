4.3. 分类模型基类¶

你可能已经注意到，在回归的情形下，从零开始的实现和使用框架功能的简洁实现非常相似。分类也是如此。由于本书中的许多模型都涉及分类，值得添加一些专门支持这一场景的功能。本节提供了一个分类模型的基类，以简化后续的代码。

pytorchmxnetjaxtensorflow
import torch
from d2l import torch as d2l

from mxnet import autograd, gluon, np, npx
from d2l import mxnet as d2l

npx.set_np()

from functools import partial
import jax
import optax
from jax import numpy as jnp
from d2l import jax as d2l

import tensorflow as tf
from d2l import tensorflow as d2l

4.3.1. Classifier 类¶

pytorchmxnetjaxtensorflow

下面我们定义Classifier类。在validation_step中，我们报告验证批次上的损失值和分类准确率。我们每处理num_val_batches个批次才绘制一次更新。这样做的好处是能生成整个验证数据上的平均损失和平均准确率。如果最后一个批次包含的样例较少，这些平均值并不完全正确，但为了保持代码简单，我们忽略这一微小差异。

class Classifier(d2l.Module):  #@save
    """The base class of classification models."""
    def validation_step(self, batch):
        Y_hat = self(*batch[:-1])
        self.plot('loss', self.loss(Y_hat, batch[-1]), train=False)
        self.plot('acc', self.accuracy(Y_hat, batch[-1]), train=False)

class Classifier(d2l.Module):  #@save
    """The base class of classification models."""
    def validation_step(self, batch):
        Y_hat = self(*batch[:-1])
        self.plot('loss', self.loss(Y_hat, batch[-1]), train=False)
        self.plot('acc', self.accuracy(Y_hat, batch[-1]), train=False)

下面我们定义Classifier类。在validation_step中，我们报告验证批次上的损失值和分类准确率。我们每处理num_val_batches个批次才绘制一次更新。这样做的好处是能生成整个验证数据上的平均损失和平均准确率。如果最后一个批次包含的样例较少，这些平均值并不完全正确，但为了保持代码简单，我们忽略这一微小差异。

我们还为 JAX 重新定义了training_step方法，因为此后所有将继承Classifier的模型都会有一个返回辅助数据的损失。 这些辅助数据可用于带有批量规范化层的模型（将在 8.5节 中解释），而在其他所有情况下， 我们让损失同时返回一个占位符（空字典）来表示辅助数据。

class Classifier(d2l.Module):  #@save
    """The base class of classification models."""
    def training_step(self, params, batch, state):
        # Here value is a tuple since models with BatchNorm layers require
        # the loss to return auxiliary data
        value, grads = jax.value_and_grad(
            self.loss, has_aux=True)(params, batch[:-1], batch[-1], state)
        l, _ = value
        self.plot("loss", l, train=True)
        return value, grads

    def validation_step(self, params, batch, state):
        # Discard the second returned value. It is used for training models
        # with BatchNorm layers since loss also returns auxiliary data
        l, _ = self.loss(params, batch[:-1], batch[-1], state)
        self.plot('loss', l, train=False)
        self.plot('acc', self.accuracy(params, batch[:-1], batch[-1], state),
                  train=False)

4.3.2. 准确率¶

给定预测的概率分布y_hat， 每当我们必须输出一个硬预测时， 我们通常选择预测概率最高的类别。 的确，许多应用都要求我们做出选择。 例如，Gmail 必须把一封电子邮件归入“主要”“社交”“更新”“论坛”或“垃圾邮件”。 它可能在内部估计概率， 但归根结底必须在这些类别中选择一个。

当预测结果与标签类别y一致时，该预测就是正确的。 分类准确率是所有预测中正确预测所占的比例。 虽然直接优化准确率可能很困难（它不可微）， 但它往往是我们最关心的性能指标。在基准测试中，它常常就是那个相关量。 因此，在训练分类器时，我们几乎总会报告它。

准确率的计算方式如下。 首先，如果y_hat是一个矩阵， 我们假设第二维存储的是每个类别的预测分数。 我们用argmax取得每一行中最大元素的下标，作为预测出的类别。 然后我们将预测类别与真实标签y逐元素比较。 由于相等运算符==对数据类型敏感， 我们把y_hat的数据类型转换为与y一致。 结果是一个包含 0（假）和 1（真）的张量。 对其求和就得到正确预测的数量。

4.3.3. 小结¶

分类是一个非常常见的问题，因此值得为它提供专门的便捷函数。分类中最为核心的是分类器的准确率。请注意，虽然我们往往主要关心准确率，但出于统计和计算上的原因，我们训练分类器时优化的却是各种其他目标。然而，无论训练期间最小化的是哪个损失函数，有一个便捷方法来根据经验评估分类器的准确率都是很有用的。
