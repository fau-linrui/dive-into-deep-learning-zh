4.2. 图像分类数据集¶

图像分类中一个广泛使用的数据集是手写数字的 MNIST 数据集 (LeCun et al., 1998)。在它于 20 世纪 90 年代发布之时，它对大多数机器学习算法构成了严峻的挑战：该数据集由 60,000 幅分辨率为 \(28 \times 28\) 像素的图像组成（外加 10,000 幅图像的测试数据集）。为了有个直观的比较，1995 年，一台拥有高达 64MB 内存和惊人 5 MFLOPs 算力的 Sun SPARCStation 5，在 AT&T 贝尔实验室被认为是机器学习领域最先进的设备。在数字识别上取得高准确率，是 20 世纪 90 年代美国邮政署（USPS）实现信件分拣自动化的关键组成部分。LeNet-5 (LeCun et al., 1995) 等深度网络、具有不变性的支持向量机 (Schölkopf et al., 1996) 以及切距离分类器 (Simard et al., 1998)，都能达到低于 1% 的错误率。

十多年来，MNIST 一直是比较机器学习算法的那个基准。 虽然它作为基准数据集有过一段辉煌的历史， 但以今天的标准来看，即使简单模型也能达到 95% 以上的分类准确率， 这使得它不适合用来区分强模型和弱模型。 更有甚者，该数据集允许达到非常高的准确率，这在许多分类问题中并不常见。 这使算法的发展偏向于某些能利用干净数据集的特定算法族，例如有效集方法和边界搜索有效集算法。 如今，MNIST 更像是一个健全性检查，而不是一个基准。ImageNet (Deng et al., 2009) 提出了一个相关得多的挑战。 不幸的是，对于本书中的许多示例和图示来说，ImageNet 太大了， 因为训练它需要的时间太长，无法让示例保持交互性。 作为替代，在接下来的几节中，我们将把讨论集中在一个性质相似但小得多的数据集上， 即 2017 年发布的 Fashion-MNIST 数据集 (Xiao et al., 2017)。 它包含 10 个服装类别的图像，分辨率为 \(28 \times 28\) 像素。

4.2.1. 加载数据集¶

由于 Fashion-MNIST 数据集非常有用，所有主流框架都提供了它的预处理版本。我们可以使用框架内置的工具将其下载并读入内存。

def text_labels(self, indices):

              'sandal', 'shirt', 'sneaker', 'bag', 'ankle boot']
    return [labels[int(i)] for i in indices]

4.2.2. 读取小批量¶

为了在从训练集和测试集读取数据时让生活更轻松， 我们使用内置的数据迭代器，而不是从头创建一个。 回想一下，在每次迭代时，数据迭代器都会 读取一个大小为batch_size的小批量数据。 我们还对训练数据迭代器中的样例进行随机打乱。

                                       num_workers=self.num_workers)

@d2l.add_to_class(FashionMNIST)  #@save
def get_dataloader(self, train):
    data = self.train if train else self.val
    process = lambda X, y: (tf.expand_dims(X, axis=3) / 255,
                            tf.cast(y, dtype='int32'))
    resize_fn = lambda X, y: (tf.image.resize_with_pad(X, *self.resize), y)
    shuffle_buf = len(data[0]) if train else 1
    return tfds.as_numpy(

            self.batch_size).map(resize_fn).shuffle(shuffle_buf))

让我们看看读取这些图像所花费的时间。尽管它是内置的加载器，但速度并没有快得惊人。尽管如此，这已经足够了，因为用深度网络处理图像所需的时间要长得多。因此，它足以保证训练网络不会受 I/O 限制。

4.2.4. 小结¶

我们现在有了一个稍微更真实的分类数据集。Fashion-MNIST 是一个服装分类数据集，由代表 10 个类别的图像组成。我们将在后续各节和章节中使用该数据集来评估各种网络设计，从简单的线性模型到先进的残差网络。正如我们处理图像时常做的那样，我们把它们读取为形状为（批量大小、通道数、高度、宽度）的张量。目前我们只有一个通道，因为图像是灰度的（上面的可视化使用了伪彩色调色板以提高可见性）。

最后，数据迭代器是高效性能的关键组成部分。例如，我们可以使用 GPU 来高效地进行图像解压、视频转码或其他预处理。只要有可能，你就应该依赖那些利用高性能计算的良好实现的数据迭代器，以免拖慢训练循环。

4.2.5. 练习¶
