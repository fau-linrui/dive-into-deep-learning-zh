# 用于分类的线性神经网络
:label:`chap_classification`

既然你已经学完了所有的机制，
现在就可以把学到的技能应用到更广泛的任务类型上了。
即使我们转向分类问题，
大部分底层流程仍然相同：
加载数据、将数据传入模型、
生成输出、计算损失、
对权重求梯度，
以及更新模型。
然而，目标值的确切形式、
输出层的参数化方式，
以及损失函数的选择，
都会做出调整以适应*分类*场景。
