15.6. 子词嵌入¶

在英语中， “helps”、“helped”和”helping”这样的单词 都是同一个单词”help”的 屈折形式。 “dog”与”dogs”之间的 关系 等同于 “cat”与”cats”之间的 关系， 并且 “boy”与”boyfriend”之间的 关系 等同于 “girl”与”girlfriend”之间的 关系。 在法语和西班牙语等 其他语言中， 许多动词有 40 多种屈折形式， 而在芬兰语中， 一个名词最多可以有 15 种格。 在语言学中， 形态学研究词的构成和词与词之间的关系。 然而， 词的内部结构 在 word2vec 中 和在 GloVe 中 都没有被探究。

15.6.1. fastText 模型¶

回想一下 word2vec 中词是如何表示的。 在跳元模型和 连续词袋模型中， 同一个词的不同屈折形式 直接由不同的向量表示， 不共享参数。 为了利用形态学信息， fastText 模型 提出了子词嵌入方法， 其中子词是一个字符 \(n\) 元语法 (Bojanowski et al., 2017)。 fastText 不是学习词级别的向量表示， 而是可以看作 子词级别的跳元模型， 其中每个中心词由其 子词向量之和表示。

让我们以单词”where”为例， 说明如何获得 fastText 中 每个中心词的子词。 首先，在单词的开头和结尾添加特殊字符“<”和“>”， 以区分前缀、后缀与其他子词。 然后，从单词中提取字符 \(n\) 元语法。 例如，当 \(n=3\) 时， 我们得到所有长度为 3 的子词：“<wh”、“whe”、“her”、“ere”、“re>”，以及特殊子词”<where>“。

在 fastText 中，对于任意词 \(w\)， 用 \(\mathcal{G}_w\) 表示 其长度在 3 到 6 之间的所有子词 及其特殊子词的并集。 词表 是所有词的子词的并集。 令 \(\mathbf{z}_g\) 为词表中子词 \(g\) 的向量， 则跳元模型中 词 \(w\) 作为中心词时的 向量 \(\mathbf{v}_w\) 是其子词向量之和：

(15.6.1)¶\[\mathbf{v}_w = \sum_{g\in\mathcal{G}_w} \mathbf{z}_g.\]

fastText 的其余部分与跳元模型相同。与跳元模型相比， fastText 中的词表更大， 导致模型参数更多。 此外， 为了计算一个词的表示， 必须对其所有子词向量 求和， 这导致更高的计算复杂度。 然而， 得益于结构相似的词之间共享的子词参数， 生僻词甚至词表外的词 在 fastText 中 可能获得更好的向量表示。

15.6.2. 字节对编码¶

在 fastText 中，所有提取的子词都必须是指定长度的，例如 \(3\) 到 \(6\)，因此词表大小无法预先确定。 为了在固定大小的词表中允许可变长度的子词， 我们可以应用一种称为字节对编码（byte pair encoding，BPE）的压缩算法 来提取子词 (Sennrich et al., 2015)。

字节对编码对训练数据集进行统计分析，以发现词内的常见符号， 例如任意长度的连续字符。 从长度为 1 的符号开始， 字节对编码迭代地合并最频繁的连续符号对，以产生新的更长的符号。 请注意，为了效率，不考虑跨越词边界的符号对。 最后，我们可以使用这样的符号作为子词来切分单词。 字节对编码及其变体已被用于 GPT-2 (Radford et al., 2019) 和 RoBERTa (Liu et al., 2019) 等流行的自然语言处理预训练模型的输入表示。 下面，我们将说明字节对编码是如何工作的。

首先，我们将符号词表初始化为所有英文字母小写字符、一个特殊的词尾符号'_'和一个特殊的未知符号'[UNK]'。

pytorchmxnet
import collections

symbols = ['a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i', 'j', 'k', 'l', 'm',
           'n', 'o', 'p', 'q', 'r', 's', 't', 'u', 'v', 'w', 'x', 'y', 'z',
           '_', '[UNK]']

           '_', '[UNK]']

由于我们不考虑跨越单词边界的符号对， 我们只需要一个字典raw_token_freqs，它将单词映射到其在 数据集中的频率（出现次数）。 请注意，特殊符号'_'被附加到每个单词上，以便 我们可以轻松地从输出符号序列（例如”a_ tall er_ man”） 恢复单词序列（例如”a taller man”）。 由于我们从只包含单个字符和特殊符号的词表开始合并过程，单词内的每对连续字符之间都会插入空格（字典token_freqs的键）。 换句话说，空格是单词内符号之间的分隔符。

pytorchmxnet
raw_token_freqs = {'fast_': 4, 'faster_': 3, 'tall_': 5, 'taller_': 4}
token_freqs = {}
for token, freq in raw_token_freqs.items():
    token_freqs[' '.join(list(token))] = raw_token_freqs[token]

我们定义以下get_max_freq_pair函数， 它返回单词内最频繁的连续符号对， 其中单词来自输入字典token_freqs的键。

pytorchmxnet
def get_max_freq_pair(token_freqs):
    pairs = collections.defaultdict(int)
    for token, freq in token_freqs.items():
        symbols = token.split()
        for i in range(len(symbols) - 1):
            # Key of `pairs` is a tuple of two consecutive symbols
            pairs[symbols[i], symbols[i + 1]] += freq
    return max(pairs, key=pairs.get)  # Key of `pairs` with the max value

作为一种基于连续符号频率的贪心方法， 字节对编码将使用以下merge_symbols函数来合并最频繁的连续符号对，以产生新的符号。

pytorchmxnet
def merge_symbols(max_freq_pair, token_freqs, symbols):
    symbols.append(''.join(max_freq_pair))
    new_token_freqs = dict()
    for token, freq in token_freqs.items():
        new_token = token.replace(' '.join(max_freq_pair),
                                  ''.join(max_freq_pair))
        new_token_freqs[new_token] = token_freqs[token]
    return new_token_freqs

现在我们对字典token_freqs的键迭代地执行字节对编码算法。在第一次迭代中，最频繁的连续符号对是't'和'a'，因此字节对编码将它们合并，产生一个新符号'ta'。在第二次迭代中，字节对编码继续合并'ta'和'l'，得到另一个新符号'tal'。

pytorchmxnet
num_merges = 10
for i in range(num_merges):
    max_freq_pair = get_max_freq_pair(token_freqs)
    token_freqs = merge_symbols(max_freq_pair, token_freqs, symbols)
    print(f'merge #{i + 1}:', max_freq_pair)

请注意，字节对编码的结果取决于所使用的数据集。 我们也可以使用从一个数据集学习到的子词 来切分另一个数据集的单词。 作为一种贪心方法，下面的segment_BPE函数尝试将单词拆分为来自输入参数symbols的最长可能子词。

pytorchmxnet
def segment_BPE(tokens, symbols):
    outputs = []
    for token in tokens:
        start, end = 0, len(token)
        cur_output = []
        # Segment token with the longest possible subwords from symbols
        while start < len(token) and start < end:
            if token[start: end] in symbols:
                cur_output.append(token[start: end])
                start = end
                end = len(token)
            else:
                end -= 1
        if start < len(token):
            cur_output.append('[UNK]')
        outputs.append(' '.join(cur_output))
    return outputs

15.6.3. 小结¶

  • fastText 模型提出了子词嵌入方法。它基于 word2vec 中的跳元模型，将中心词表示为其子词向量之和。

  • 字节对编码对训练数据集进行统计分析，以发现词内的常见符号。作为一种贪心方法，字节对编码迭代地合并最频繁的连续符号对。

  • 子词嵌入可以提高生僻词和词表外的词的表示质量。
