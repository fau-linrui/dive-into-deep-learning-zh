11.2. 基于相似性的注意力汇聚¶

既然我们已经介绍了注意力机制的主要组成部分，下面就让我们把它们用于一个相当经典的场景，即通过核密度估计 (Nadaraya, 1964, Watson, 1964) 进行回归和分类。这段绕路只是提供额外的背景知识：它完全是可选的，必要时可以跳过。 Nadaraya–Watson 估计量的核心在于依赖某种相似性核\(\alpha(\mathbf{q}, \mathbf{k})\)，它把查询\(\mathbf{q}\)与键\(\mathbf{k}\)联系起来。一些常见的核如下

(11.2.1)¶\[\begin{split}\begin{aligned} \alpha(\mathbf{q}, \mathbf{k}) & = \exp\left(-\frac{1}{2} \|\mathbf{q} - \mathbf{k}\|^2 \right) && \textrm{Gaussian;} \\ \alpha(\mathbf{q}, \mathbf{k}) & = 1 \textrm{ if } \|\mathbf{q} - \mathbf{k}\| \leq 1 && \textrm{Boxcar;} \\ \alpha(\mathbf{q}, \mathbf{k}) & = \mathop{\mathrm{max}}\left(0, 1 - \|\mathbf{q} - \mathbf{k}\|\right) && \textrm{Epanechikov.} \end{aligned}\end{split}\]

我们还有很多可供选择的核。关于更全面的综述，以及核的选择如何与核密度估计（有时也称为Parzen 窗（Parzen Windows）:cite:parzen1957consistent）相关联，可参见维基百科条目。所有这些都是启发式核，并且可以调参。例如，我们不仅可以全局地调整宽度，甚至可以按坐标逐一调整宽度。无论如何，它们都会导出下式，对回归和分类同样适用：

(11.2.2)¶\[f(\mathbf{q}) = \sum_i \mathbf{v}_i \frac{\alpha(\mathbf{q}, \mathbf{k}_i)}{\sum_j \alpha(\mathbf{q}, \mathbf{k}_j)}.\]

在（标量）回归情形下，观测数据为特征和标签\((\mathbf{x}_i, y_i)\)，此时\(\mathbf{v}_i = y_i\)是标量，\(\mathbf{k}_i = \mathbf{x}_i\)是向量，查询\(\mathbf{q}\)表示应当计算\(f\)的新位置。在（多类）分类情形下，我们对\(y_i\)使用独热编码来得到\(\mathbf{v}_i\)。该估计量的一个便利性质是它无需训练。更进一步，如果随着数据量增加而适当地收窄核，该方法是一致的 (Mack and Silverman, 1982)，即它会收敛到某种统计最优解。让我们先来考察一些核。

11.2.1. 核与数据¶

本节定义的所有核\(\alpha(\mathbf{k}, \mathbf{q})\)都是平移和旋转不变的；也就是说，如果我们以同样的方式平移和旋转\(\mathbf{k}\)和\(\mathbf{q}\)，\(\alpha\)的值保持不变。为简单起见，我们因此选取标量参数\(k, q \in \mathbb{R}\)，并选取键\(k = 0\)作为原点。这得到：

11.2.2. 通过 Nadaraya–Watson 回归进行注意力汇聚¶

现在有了数据和核，我们只需要一个计算核回归估计值的函数。请注意，为了进行一些简单的诊断，我们还想得到相对的核权重。因此，我们先计算所有训练特征（协变量）x_train与所有验证特征x_val之间的核。这会得到一个矩阵，随后我们对其规范化。当它与训练标签y_train相乘时，我们就得到了估计值。

回想 (11.1.1) 中的注意力汇聚。令每个验证特征为一个查询，每个训练特征-标签对为一个键-值对。于是，规范化后的相对核权重（下面的attention_w）就是注意力权重。

pytorchmxnetjaxtensorflow
def nadaraya_watson(x_train, y_train, x_val, kernel):
    dists = x_train.reshape((-1, 1)) - x_val.reshape((1, -1))
    # Each column/row corresponds to each query/key
    k = kernel(dists).type(torch.float32)
    # Normalization over keys for each query
    attention_w = k / k.sum(0)
    y_hat = y_train@attention_w
    return y_hat, attention_w

def nadaraya_watson(x_train, y_train, x_val, kernel):

    # Each column/row corresponds to each query/key
    k = kernel(dists).astype(np.float32)
    # Normalization over keys for each query
    attention_w = k / k.sum(0)
    y_hat = np.dot(y_train, attention_w)
    return y_hat, attention_w

def nadaraya_watson(x_train, y_train, x_val, kernel):
    dists = tf.reshape(x_train, (-1, 1)) - tf.reshape(x_val, (1, -1))
    # Each column/row corresponds to each query/key
    k = tf.cast(kernel(dists), tf.float32)
    # Normalization over keys for each query
    attention_w = k / tf.reduce_sum(k, 0)
    y_hat = tf.transpose(tf.transpose(y_train)@attention_w)
    return y_hat, attention_w

首先引人注意的是，三个非平凡核（Gaussian、Boxcar 和 Epanechikov）都产生了相当可用的估计，与真实函数相差不太远。只有导致平凡估计\(f(x) = \frac{1}{n} \sum_i y_i\)的常数核给出了相当不切实际的结果。让我们更仔细地考察注意力权重：

可视化清楚地显示了为什么 Gaussian、Boxcar 和 Epanechikov 的估计非常相似：毕竟，尽管核的函数形式不同，它们却由非常相似的注意力权重导出。这引出了一个问题：是否总是如此。

11.2.3. 调整注意力汇聚¶

我们可以把高斯核换成宽度不同的核。也就是说，我们可以使用\(\alpha(\mathbf{q}, \mathbf{k}) = \exp\left(-\frac{1}{2 \sigma^2} \|\mathbf{q} - \mathbf{k}\|^2 \right)\)，其中\(\sigma^2\)决定核的宽度。让我们看看这是否会影响结果。

pytorchmxnetjaxtensorflow
sigmas = (0.1, 0.2, 0.5, 1)
names = ['Sigma ' + str(sigma) for sigma in sigmas]

def gaussian_with_width(sigma):
    return (lambda x: torch.exp(-x**2 / (2*sigma**2)))

kernels = [gaussian_with_width(sigma) for sigma in sigmas]
plot(x_train, y_train, x_val, y_val, kernels, names)

显然，核越窄，估计就越不平滑。与此同时，它也能更好地适应局部变化。让我们看看相应的注意力权重。

plot(x_train, y_train, x_val, y_val, kernels, names, attention=True)

正如我们所料，核越窄，较大注意力权重的范围也越窄。同样清楚的是，选取相同的宽度可能并不理想。事实上，Silverman (1986) 提出了一种依赖局部密度的启发式方法。人们还提出了更多这类“技巧”。例如，Norelli et al. (2022) 使用了类似的最近邻插值技术来设计跨模态的图像与文本表示。

敏锐的读者可能会想，我们为什么要对一个已有半个多世纪之久的方法做如此深入的探讨。第一，它是现代注意力机制最早的先驱之一。第二，它非常适合可视化。第三，同样重要的是，它展示了手工设计注意力机制的局限。一个更好的策略是通过学习查询和键的表示来学习这一机制。这正是我们将在后续小节中着手做的事情。

11.2.4. 小结¶

Nadaraya–Watson 核回归是当前注意力机制的早期先驱。 它几乎不需要训练或调参就可以直接用于分类或回归。 注意力权重根据查询与键之间的相似性（或距离）来分配，同时也根据可用的相似观测的数量来分配。

11.2.5. 练习¶

  1. Parzen 窗密度估计由\(\hat{p}(\mathbf{x}) = \frac{1}{n} \sum_i k(\mathbf{x}, \mathbf{x}_i)\)给出。证明：对于二元分类，由 Parzen 窗得到的函数\(\hat{p}(\mathbf{x}, y=1) - \hat{p}(\mathbf{x}, y=-1)\)等价于 Nadaraya–Watson 分类。

  2. 实现随机梯度下降，以学习 Nadaraya–Watson 回归中核宽度的合适取值。

    1. 如果直接使用上述估计来最小化\((f(\mathbf{x_i}) - y_i)^2\)会发生什么？提示：\(y_i\)是用于计算\(f\)的项的一部分。

    2. 把\((\mathbf{x}_i, y_i)\)从\(f(\mathbf{x}_i)\)的估计中移除，然后对核宽度进行优化。你还会观察到过拟合吗？

  3. 假设所有\(\mathbf{x}\)都位于单位球面上，即都满足\(\|\mathbf{x}\| = 1\)。你能简化指数中的\(\|\mathbf{x} - \mathbf{x}_i\|^2\)项吗？提示：我们稍后会看到，这与点积注意力密切相关。

  4. 回想 Mack and Silverman (1982) 证明了 Nadaraya–Watson 估计是一致的。随着数据增多，你应该以多快的速度减小注意力机制的尺度？请为你的答案提供一些直觉解释。它依赖于数据的维数吗？如何依赖？
