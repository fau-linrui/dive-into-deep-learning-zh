9.6. 循环神经网络的简洁实现¶

与大多数从零开始的实现一样，9.5节 的设计目的 是让我们深入了解每个组件是如何工作的。 但是，当你每天都要使用 RNN 或者编写生产代码时， 你会希望更多地依赖库： 这些库既能减少实现时间（为常见模型和函数提供库代码）， 又能减少计算时间（对这些库实现进行极致的优化）。 本节将展示如何利用深度学习框架提供的高级 API， 更高效地实现同一个语言模型。 与之前一样，我们首先加载The Time Machine数据集。

pytorchmxnetjaxtensorflow
import torch
from torch import nn
from torch.nn import functional as F
from d2l import torch as d2l

from mxnet import np, npx
from mxnet.gluon import nn, rnn
from d2l import mxnet as d2l

npx.set_np()

from flax import linen as nn
from jax import numpy as jnp
from d2l import jax as d2l

import tensorflow as tf
from d2l import tensorflow as d2l

9.6.1. 定义模型¶

我们使用高级 API 实现的 RNN 来定义下面的类。

pytorchmxnetjaxtensorflow
class RNN(d2l.Module):  #@save
    """The RNN model implemented with high-level APIs."""
    def __init__(self, num_inputs, num_hiddens):
        super().__init__()
        self.save_hyperparameters()
        self.rnn = nn.RNN(num_inputs, num_hiddens)

    def forward(self, inputs, H=None):
        return self.rnn(inputs, H)

具体来说，为了初始化隐藏状态， 我们调用成员方法 begin_state。 它返回一个列表，列表中含有小批量中每个样例的初始隐藏状态， 其形状为（隐藏层数，批量大小，隐藏单元数）。 对于之后要介绍的一些模型（例如长短期记忆网络）， 这个列表还会包含其他信息。

class RNN(d2l.Module):  #@save
    """The RNN model implemented with high-level APIs."""
    def __init__(self, num_hiddens):
        super().__init__()
        self.save_hyperparameters()
        self.rnn = rnn.RNN(num_hiddens)

    def forward(self, inputs, H=None):
        if H is None:
            H, = self.rnn.begin_state(inputs.shape[1], ctx=inputs.ctx)
        outputs, (H, ) = self.rnn(inputs, (H, ))
        return outputs, H

截至目前，Flax 还没有提供用于简洁实现普通 RNN 的 RNNCell。 对于 LSTM 和 GRU 等更高级的 RNN 变体， 则可以使用 Flax 的 linen API。

class RNN(nn.Module):  #@save
    """The RNN model implemented with high-level APIs."""
    num_hiddens: int

    @nn.compact
    def __call__(self, inputs, H=None):
        raise NotImplementedError

class RNN(d2l.Module):  #@save
    """The RNN model implemented with high-level APIs."""
    def __init__(self, num_hiddens):
        super().__init__()
        self.save_hyperparameters()
        self.rnn = tf.keras.layers.SimpleRNN(
            num_hiddens, return_sequences=True, return_state=True,
            time_major=True)

    def forward(self, inputs, H=None):
        outputs, H = self.rnn(inputs, H)
        return outputs, H

下面的 RNNLM 类继承 9.5节 中的 RNNLMScratch 类， 定义了一个完整的基于 RNN 的语言模型。 请注意，我们需要单独创建一个全连接输出层。

class RNNLM(d2l.RNNLMScratch):  #@save
    """The RNN-based language model implemented with high-level APIs."""
    training: bool = True

    def setup(self):
        self.linear = nn.Dense(self.vocab_size)

    def forward(self, X, state=None):

        rnn_outputs, _ = self.rnn(embs, state, self.training)

    def output_layer(self, hiddens):
        return tf.transpose(self.linear(hiddens), (1, 0, 2))

9.6.3. 小结¶

深度学习框架的高级 API 提供了标准 RNN 的实现。 这些库帮助我们避免浪费时间重新实现标准模型。 此外，框架中的实现通常经过高度优化， 与从零实现的版本相比，可以带来显著的（计算）性能提升。
