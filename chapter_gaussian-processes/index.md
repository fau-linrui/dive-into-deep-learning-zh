# 高斯过程
:label:`chap_gp`

**Andrew Gordon Wilson**（*纽约大学与亚马逊*）


高斯过程（Gaussian process，GP）无处不在。你其实已经遇到过许多高斯过程的例子，只是没有意识到而已。任何关于参数是线性的、并且参数服从高斯分布的模型都是高斯过程。这一类模型既包括离散模型，如随机游走和自回归过程，也包括连续模型，如贝叶斯线性回归模型、多项式、傅里叶级数、径向基函数，甚至包括具有无穷多个隐藏单元的神经网络。有一个流传的笑话：“一切模型都是高斯过程的特例”。

了解高斯过程很重要，原因有三：（1）它们提供了建模的 _函数空间_（function space）视角，这使得理解包括深度神经网络在内的各种模型类别变得容易得多；（2）它们有着极其广泛的应用，并且在这些应用中处于最先进水平，包括主动学习、超参数学习、自动机器学习（auto-ML）和时空回归；（3）过去几年里，算法上的进展使高斯过程变得越来越可扩展、越来越实用，并通过 [GPyTorch](https://gpytorch.ai) 等框架 :cite:`Gardner.Pleiss.Weinberger.Bindel.Wilson.2018` 与深度学习相协调。事实上，高斯过程与深度神经网络并不是相互竞争的方案，而是高度互补的，可以结合起来产生巨大的效果。这些算法进展不仅与高斯过程相关，还提供了在深度学习中广泛有用的数值方法基础。

本章介绍高斯过程。在引言笔记本中，我们首先从直观上推理高斯过程是什么，以及它们如何直接对函数建模。在先验笔记本中，我们重点关注如何设定高斯过程的先验。我们会把传统的权重空间建模方法与函数空间直接联系起来，这将有助于我们思考和构建、理解机器学习模型，包括深度神经网络。接着，我们介绍常用的协方差函数，也称为 _核函数_（kernel），它们控制高斯过程的泛化性质。给定核函数的高斯过程定义了函数上的一个先验。在推断笔记本中，我们将展示如何利用数据推断 _后验_，从而进行预测。该笔记本既包含从零开始编写的高斯过程预测代码，也包含对 GPyTorch 的介绍。在后续笔记本中，我们将介绍高斯过程背后的数值方法，这些方法对于扩展高斯过程很有用，同时也是深度学习中强大的通用基础，并可用于深度学习中的超参数调优等高级用例。我们的示例将使用 GPyTorch，它使高斯过程具备可扩展性，并与深度学习功能和 PyTorch 紧密集成。
