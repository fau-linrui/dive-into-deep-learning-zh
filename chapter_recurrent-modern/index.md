# 现代循环神经网络
:label:`chap_modern_rnn`

上一章介绍了循环神经网络（RNN）背后的关键思想。
然而，正如卷积神经网络一样，
RNN 架构也经历了大量的创新，
最终形成了若干在实践中被证明成功的复杂设计。
特别是，最流行的设计都带有一些机制，
用来缓解 RNN 出了名的数值不稳定性，
其典型表现就是梯度消失和梯度爆炸。
回想一下，在 :numref:`chap_rnn` 中，
我们通过一种简单粗暴的梯度裁剪启发式方法来处理梯度爆炸。
尽管这种技巧很有效，但它仍未解决梯度消失问题。

在本章中，我们介绍序列上最成功的 RNN 架构背后的关键思想，
这些思想源于两篇论文。
第一篇是*Long Short-Term Memory* :cite:`Hochreiter.Schmidhuber.1997`，
它引入了*记忆单元*（memory cell），
这是一种计算单元，用来替代网络中隐藏层的传统节点。
借助这些记忆单元，网络能够克服早期循环网络在训练中遇到的困难。
直观地说，记忆单元通过让每个记忆单元内部状态中的值
沿着权重为 1 的循环边在多个连续时间步上逐级传递，
从而避免梯度消失问题。
一组乘法门帮助网络确定两件事：
哪些输入可以进入记忆状态，
以及记忆状态的内容应在何时影响模型的输出。

第二篇论文是*Bidirectional Recurrent Neural Networks* :cite:`Schuster.Paliwal.1997`，
它引入了一种架构，其中来自未来（后续时间步）
和过去（先前时间步）的信息
都被用来确定序列中任意位置的输出。
这与以前的网络形成对比，
在以前的网络中只有过去的输入能影响输出。
双向 RNN 已成为自然语言处理中序列标注任务以及其他众多任务的主流方法。
幸运的是，这两项创新并不互斥，
并且已被成功结合起来，用于音素分类
:cite:`Graves.Schmidhuber.2005` 和手写识别 :cite:`graves2008novel`。

本章前几节将解释长短期记忆网络（LSTM）架构、
一个称为门控循环单元（GRU）的轻量级版本、
双向 RNN 背后的关键思想，
并简要说明如何把 RNN 层堆叠起来形成深度 RNN。
随后，我们将探讨 RNN 在序列到序列任务中的应用，
介绍机器翻译以及*编码器-解码器*（encoder-decoder）架构和*束搜索*（beam search）等关键思想。
