10.3. 深度循环神经网络¶

到目前为止，我们关注的是由序列输入、 单个隐藏 RNN 层和一个输出层组成的网络。 尽管任意时间步的输入与对应的输出之间只有一个隐藏层， 但从某种意义上说，这些网络是“深”的。 第一个时间步的输入可以影响最后时间步 \(T\) 的输出 （通常是在数百甚至数千步之后）。 这些输入要经过循环层的 \(T\) 次应用， 才到达最终输出。 然而，我们通常还希望保留表达能力， 以刻画给定时间步的输入 与该同一时间步的输出之间的复杂关系。 因此，我们常常构建不仅在时间方向上深、 而且在输入到输出方向上也深的 RNN。 这正是我们在介绍多层感知机和深度 CNN 时 已经遇到过的“深度”概念。

构建这类深度 RNN 的标准方法非常简单： 把 RNN 一层层堆叠起来。 给定长度为 \(T\) 的序列， 第一个 RNN 产生输出序列，其长度也是 \(T\)。 这些输出依次构成下一个 RNN 层的输入。 在这一短节中，我们说明这种设计模式， 并给出一个如何编写这种堆叠 RNN 的简单示例。 下面，图10.3.1 展示了一个具有 \(L\) 个隐藏层的深度 RNN。 每个隐藏状态都对一个序列输入进行操作， 并产生一个序列输出。 此外，每个时间步的任意 RNN 单元（图10.3.1 中的白色方框） 都同时依赖于同一层在上一时间步的值 和上一层在同一时间步的值。

形式化地说，假设在时间步 \(t\)， 我们有一个小批量输入 \(\mathbf{X}_t \in \mathbb{R}^{n \times d}\) （样例数 \(=n\)；每个样例的输入数 \(=d\)）。 在同一时间步，设第 \(l^\textrm{th}\) 个隐藏层 （\(l=1,\ldots,L\)）的隐藏状态为 \(\mathbf{H}_t^{(l)} \in \mathbb{R}^{n \times h}\) （隐藏单元数 \(=h\)）， 输出层变量为 \(\mathbf{O}_t \in \mathbb{R}^{n \times q}\) （输出数：\(q\)）。 令 \(\mathbf{H}_t^{(0)} = \mathbf{X}_t\)， 则使用激活函数 \(\phi_l\) 的第 \(l^\textrm{th}\) 个隐藏层 的隐藏状态计算如下：

(10.3.1)¶\[\mathbf{H}_t^{(l)} = \phi_l(\mathbf{H}_t^{(l-1)} \mathbf{W}_{\textrm{xh}}^{(l)} + \mathbf{H}_{t-1}^{(l)} \mathbf{W}_{\textrm{hh}}^{(l)} + \mathbf{b}_\textrm{h}^{(l)}),\]

其中权重 \(\mathbf{W}_{\textrm{xh}}^{(l)} \in \mathbb{R}^{h \times h}\) 和 \(\mathbf{W}_{\textrm{hh}}^{(l)} \in \mathbb{R}^{h \times h}\)， 连同偏置 \(\mathbf{b}_\textrm{h}^{(l)} \in \mathbb{R}^{1 \times h}\)， 是第 \(l^\textrm{th}\) 个隐藏层的模型参数。

最后，输出层的计算只基于第 \(L^\textrm{th}\) 个（即最后一个）隐藏层的隐藏状态：

(10.3.2)¶\[\mathbf{O}_t = \mathbf{H}_t^{(L)} \mathbf{W}_{\textrm{hq}} + \mathbf{b}_\textrm{q},\]

其中权重 \(\mathbf{W}_{\textrm{hq}} \in \mathbb{R}^{h \times q}\) 和偏置 \(\mathbf{b}_\textrm{q} \in \mathbb{R}^{1 \times q}\) 是输出层的模型参数。

与多层感知机一样，隐藏层数 \(L\) 和隐藏单元数 \(h\) 是我们可以调的超参数。 常见的 RNN 层宽度（\(h\)）在 \((64, 2056)\) 范围内， 常见的深度（\(L\)）在 \((1, 8)\) 范围内。 此外，只要把 (10.3.1) 中的隐藏状态计算 替换为 LSTM 或 GRU 中的相应计算， 我们就能轻松得到深度门控 RNN。

Flax 在实现 RNN 时采取极简方式。 在 RNN 中定义层数或将层数与暂退法结合， 这些功能并非开箱即用。 我们的简洁实现将使用所有内置功能， 并在其上增加 num_layers 和 dropout 功能。 代码推广了我们在 10.2节 中使用的实现， 允许显式指定层数， 而不是采用默认的仅一层。

class GRU(d2l.RNN):  #@save
    """The multilayer GRU model."""
    num_hiddens: int
    num_layers: int
    dropout: float = 0

    @nn.compact
    def __call__(self, X, state=None, training=False):
        outputs = X
        new_state = []
        if state is None:
            batch_size = X.shape[1]
            state = [nn.GRUCell.initialize_carry(jax.random.PRNGKey(0),
                    (batch_size,), self.num_hiddens)] * self.num_layers

        GRU = nn.scan(nn.GRUCell, variable_broadcast="params",
                      in_axes=0, out_axes=0, split_rngs={"params": False})

        # Introduce a dropout layer after every GRU layer except last
        for i in range(self.num_layers - 1):
            layer_i_state, X = GRU()(state[i], outputs)
            new_state.append(layer_i_state)
            X = nn.Dropout(self.dropout, deterministic=not training)(X)

        # Final GRU layer without dropout
        out_state, X = GRU()(state[-1], X)
        new_state.append(out_state)
        return X, jnp.array(new_state)

幸运的是，实现多层 RNN 所需的许多细节 在高级 API 中都可以直接获得。 我们的简洁实现将使用这些内置功能。 代码推广了我们在 10.2节 中使用的实现， 让我们能够显式指定层数， 而不是采用默认的仅一层。

class GRU(d2l.RNN):  #@save
    """The multilayer GRU model."""
    def __init__(self, num_hiddens, num_layers, dropout=0):
        d2l.Module.__init__(self)
        self.save_hyperparameters()
        gru_cells = [tf.keras.layers.GRUCell(num_hiddens, dropout=dropout)
                     for _ in range(num_layers)]
        self.rnn = tf.keras.layers.RNN(gru_cells, return_sequences=True,
                                       return_state=True, time_major=True)

    def forward(self, X, state=None):
        outputs, *state = self.rnn(X, state)
        return outputs, state

10.3.3. 小结¶

在深度 RNN 中，隐藏状态信息会传递给当前层的下一时间步 以及下一层的当前时间步。 深度 RNN 有许多不同的变体， 例如 LSTM、GRU 或普通 RNN。 方便的是，这些模型都可以作为 深度学习框架高级 API 的一部分直接使用。 模型的初始化需要谨慎处理。 总的来说，深度 RNN 需要相当多的工作 （例如学习率和裁剪），才能确保正确收敛。
