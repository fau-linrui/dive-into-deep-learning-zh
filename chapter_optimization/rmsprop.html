12.8. RMSProp¶

12.7节 中的一个关键问题是，学习率按预先设定的调度策略下降，其量级实际上为 \(\mathcal{O}(t^{-\frac{1}{2}})\)。这对凸问题通常是合适的，但对非凸问题（例如深度学习中遇到的问题）可能并不理想。然而，Adagrad 的按坐标自适应性作为一种预条件子（preconditioner）是非常理想的。

Tieleman and Hinton (2012) 提出了 RMSProp 算法，作为一种简单的修正，把学习率调度与按坐标自适应的学习率解耦。问题在于，Adagrad 将梯度 \(\mathbf{g}_t\) 的平方累积到状态向量 \(\mathbf{s}_t = \mathbf{s}_{t-1} + \mathbf{g}_t^2\) 中。结果，由于缺少规范化，\(\mathbf{s}_t\) 会无界地持续增长，在算法收敛时基本上呈线性增长。

解决这个问题的一种方法是用 \(\mathbf{s}_t / t\)。对于 \(\mathbf{g}_t\) 的合理分布，这样做会收敛。遗憾的是，由于该过程会记住数值的完整轨迹，可能要经过很长时间，极限行为才开始起作用。另一种方法是使用泄漏平均值（leaky average），与我们在动量法中使用的方式相同，即 \(\mathbf{s}_t \leftarrow \gamma \mathbf{s}_{t-1} + (1-\gamma) \mathbf{g}_t^2\)，其中参数 \(\gamma > 0\)。保持其他所有部分不变，就得到了 RMSProp 算法。

12.8.1. 算法¶

让我们详细写出这些方程。

(12.8.1)¶\[\begin{split}\begin{aligned} \mathbf{s}_t & \leftarrow \gamma \mathbf{s}_{t-1} + (1 - \gamma) \mathbf{g}_t^2, \\ \mathbf{x}_t & \leftarrow \mathbf{x}_{t-1} - \frac{\eta}{\sqrt{\mathbf{s}_t + \epsilon}} \odot \mathbf{g}_t. \end{aligned}\end{split}\]

常数 \(\epsilon > 0\) 通常取为 \(10^{-6}\)，以确保不会出现除以零或步长过大的情况。有了这一展开式，我们现在就可以独立于按坐标施加的缩放来控制学习率 \(\eta\)。就泄漏平均值而言，我们可以采用之前在动量法中应用的同样推理。展开 \(\mathbf{s}_t\) 的定义可得

(12.8.2)¶\[\begin{split}\begin{aligned} \mathbf{s}_t & = (1 - \gamma) \mathbf{g}_t^2 + \gamma \mathbf{s}_{t-1} \\ & = (1 - \gamma) \left(\mathbf{g}_t^2 + \gamma \mathbf{g}_{t-1}^2 + \gamma^2 \mathbf{g}_{t-2} + \ldots, \right). \end{aligned}\end{split}\]

正如前面在 12.6节 中那样，我们使用 \(1 + \gamma + \gamma^2 + \ldots, = \frac{1}{1-\gamma}\)。因此，权重之和被规范化为 \(1\)，一次观测的半衰期为 \(\gamma^{-1}\)。下面我们针对不同的 \(\gamma\) 取值，可视化过去 40 个时间步的权重。

pytorchmxnettensorflow
import math
import torch
from d2l import torch as d2l

d2l.set_figsize()
gammas = [0.95, 0.9, 0.8, 0.7]
for gamma in gammas:
    x = torch.arange(40).detach().numpy()

接下来，我们实现用于深度网络的 RMSProp。这同样简单直白。

def init_rmsprop_states(feature_dim):
    s_w = torch.zeros((feature_dim, 1))
    s_b = torch.zeros(1)
    return (s_w, s_b)

def rmsprop(params, states, hyperparams):
    gamma, eps = hyperparams['gamma'], 1e-6
    for p, s in zip(params, states):
        with torch.no_grad():
            s[:] = gamma * s + (1 - gamma) * torch.square(p.grad)
            p[:] -= hyperparams['lr'] * p.grad / torch.sqrt(s + eps)
        p.grad.data.zero_()

def init_rmsprop_states(feature_dim):
    s_w = tf.Variable(tf.zeros((feature_dim, 1)))
    s_b = tf.Variable(tf.zeros(1))
    return (s_w, s_b)

def rmsprop(params, grads, states, hyperparams):
    gamma, eps = hyperparams['gamma'], 1e-6
    for p, s, g in zip(params, states, grads):
        s[:].assign(gamma * s + (1 - gamma) * tf.math.square(g))
        p[:].assign(p - hyperparams['lr'] * g / tf.math.sqrt(s + eps))

我们将初始学习率设为 0.01，权重项 \(\gamma\) 设为 0.9。也就是说，\(\mathbf{s}\) 平均聚合了过去 \(1/(1-\gamma) = 10\) 次梯度平方的观测值。

12.8.4. 小结¶

  • RMSProp 与 Adagrad 非常相似，两者都用梯度的平方来缩放系数。

  • RMSProp 与动量法一样使用泄漏平均值。但是，RMSProp 使用该技术来调整逐系数的预条件子。

  • 在实践中，学习率需要由实验者进行调度。

  • 系数 \(\gamma\) 决定了调整逐坐标缩放时历史记录有多长。

  3. 在真实的机器学习问题上试验 RMSProp，例如在 Fashion-MNIST 上训练。尝试采用不同的学习率调整方案。

  4. 你会随着优化的推进而调整 \(\gamma\) 吗？RMSProp 对此有多敏感？
