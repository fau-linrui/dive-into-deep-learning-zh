# 计算性能
:label:`chap_performance`

在深度学习中，
数据集和模型通常都很大，
这涉及大量的计算。
因此，计算性能非常重要。
本章将重点关注影响计算性能的主要因素：
命令式编程、符号式编程、异步计算、自动并行和多 GPU 计算。
通过学习本章，你可以进一步改进前面各章中实现的那些模型的计算性能，
例如，在不影响准确率的前提下缩短训练时间。
